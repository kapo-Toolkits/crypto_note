# დაშიფრული ჩანაწერი (crypto_note)

ორ ადამიანს შორის დაშიფრული ტექსტის გაცვლა საერთო PIN-ით. შედეგი
ისეა დაფორმატებული, რომ მოხერხებულია ხელით ქაღალდზე გადასაწერად.

🔗 **ვებ-აპი:** https://text.qgis.ge/
📱 **Android APK:** [ჩამოტვირთვა (Releases)](https://github.com/kapo-Toolkits/crypto_note/releases/latest)

## როგორ მუშაობს

- **რეჟიმი:** დაშიფვრა / განშიფვრა
- **ტექსტი:** ჩაწერე შეტყობინება
- **PIN:** საერთო კოდი, რომელიც ორივემ იცის
- **შედეგი:** Crockford Base32, 5-სიმბოლოიან ჯგუფებად — ადვილი გადასაწერი
- **📷 QR-ის სკანირება:** დააჭირე „QR-ის სკანირება", დაასკანერე კოდი და
  წაკითხული ტექსტი პირდაპირ ავსებს ველს — მოსახერხებელია დაშიფრული ტექსტის
  QR-ის სახით გაცვლისას (Android + ვები).

განშიფვრისას input ავტომატურად ნორმალიზდება (uppercase, ჰარები/ხაზები
იშლება, `O→0`, `I/L→1`), ამიტომ ხელით გადაწერისას მცირე შეცდომები არ უშლის ხელს.

## კრიპტოგრაფია

| | |
|---|---|
| ალგორითმი | AES-GCM 256-bit |
| გასაღები | PBKDF2, 100000 iteration, SHA-256 |
| Salt | ფიქსირებული (`saidumlo-minaweri-v1`) |
| IV | 12 შემთხვევითი ბაიტი, ciphertext-ის დასაწყისში |
| კოდირება | Crockford Base32 (გამოტოვებული I, L, O, U) |

> ⚠️ უსაფრთხოება მთლიანად PIN-ის სიძლიერეზეა დამოკიდებული. გამოიყენე
> გრძელი, რთული PIN. salt ფიქსირებულია — ერთი და იგივე ტექსტი + PIN
> ყოველ ჯერზე სხვადასხვა შედეგს იძლევა შემთხვევითი IV-ის წყალობით.
